Cài bot lên MetaTrader trên máy tính

Áp dụng cho Windows. Bot là file .ex5, chạy trên MetaTrader 5 (MT5). Bot chỉ chạy khi máy tính và MetaTrader đang bật.

Các bước

  1. Cài MetaTrader
  2. Đăng nhập tài khoản
  3. Chép bot vào Experts
  4. Bật Algo Trading
  5. Gắn bot vào biểu đồ
  6. Kiểm tra bot chạy
  7. Chạy 24/5 bằng VPS

  1. Cài MetaTrader 5

    Tải MetaTrader 5 từ trang của sàn bạn dùng (Exness hoặc Vantage, mục Nền tảng). Cài như phần mềm bình thường.

    Nên tải bản của sàn thay vì bản chung trên mạng — đã có sẵn danh sách server của sàn, đăng nhập nhanh hơn.

  2. Đăng nhập tài khoản giao dịch

    Mở MetaTrader → File → Login to Trade Account. Nhập số tài khoản, mật khẩu giao dịch và chọn đúng server (ví dụ Exness-MT5Real8).

    Đăng nhập thành công khi góc dưới bên phải hiện tốc độ kết nối (ví dụ 35 ms), không phải "No connection".

  3. Chép file bot vào thư mục Experts

    • Trong MetaTrader chọn File → Open Data Folder
    • Mở thư mục MQL5\Experts
    • Dán file bot .ex5 vào đây
    • Nếu bot có file .set, chép vào MQL5\Presets

    Quay lại MetaTrader, trong cửa sổ Navigator (Ctrl+N) chuột phải vào Expert Advisors → Refresh. Bot sẽ hiện trong danh sách.

  4. Bật Algo Trading

    Bấm nút Algo Trading trên thanh công cụ cho đến khi biểu tượng chuyển xanh.

    Vào Tools → Options → tab Expert Advisors, tick Allow algorithmic trading. Chỉ tick "Allow DLL imports" nếu hướng dẫn của bot yêu cầu.

  5. Gắn bot vào biểu đồ

    • Mở biểu đồ đúng cặp tiền và khung thời gian bot yêu cầu (ví dụ XAUUSD, M15)
    • Kéo bot từ Navigator thả vào biểu đồ
    • Tab Common: tick Allow Algo Trading
    • Tab Inputs: bấm Load → chọn file .set đã chép ở bước 3 → OK
    Mỗi biểu đồ chỉ gắn 1 bot. Muốn chạy bot trên nhiều cặp, mở thêm biểu đồ cho từng cặp.

  6. Kiểm tra bot đang chạy

    Góc trên bên phải biểu đồ hiện tên bot kèm biểu tượng mũ xanh. Mở tab Experts ở cửa sổ Toolbox (Ctrl+T) — thấy dòng như sau là ổn:

    2026.10.15 09:00:01.120 GoldTrendEA (XAUUSD,M15) loaded successfully
    2026.10.15 09:00:01.135 automated trading is enabled

    Nếu thấy "automated trading is disabled": kiểm tra lại nút Algo Trading ở bước 4.

  7. Chạy 24/5 bằng VPS (nên làm)

    Tắt máy là bot dừng. Để bot chạy liên tục, thuê VPS Windows (máy chủ ảo) rồi cài MetaTrader và bot lên đó theo đúng các bước trên. Một số sàn tặng VPS miễn phí khi tài khoản đủ điều kiện — hỏi mình để được hướng dẫn.

Kẹt ở bước nào?
